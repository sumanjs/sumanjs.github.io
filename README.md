# sumanjs.github.io

The public Astro marketing site for **Suman**.

A systems-minded test runner ecosystem with parallel execution, reporters, watch workflows, and daemon tooling.

The Astro build preserves the repository's existing tutorial, JSDoc, font, image, script, and stylesheet artifacts alongside the new homepage.

## Development

Use Node.js 22.22.1 or newer.

```sh
npm ci
npm run dev
npm run build
```

Astro writes the production site to `dist/`. The committed GitHub Actions workflow builds pull requests and deploys the default branch to GitHub Pages.
